# rf-02: Transmission-line impedance from the layout and fab stackup
Status: proposed
Goal: rf-review
Node: any
Deliverable: slides
Accept: user
Verify: ./run uv run pytest tests/test_impedance.py -q && ./run tools/build_report.py analysis/03_impedance --check
Hardware: none

## Goal
The impedance of every RF trace segment, computed from the geometry actually in
`kicad/fmcw3.kicad_pcb` and from JLCPCB's published 6-layer controlled-impedance stackups. It
holds when the `03_impedance` report lists each RF net's segments with width, gap, reference
layer and impedance, and flags those outside 50 ohm plus or minus 10 percent.

## Steps
1. `analysis/03_impedance/extract.py`: read the board file; for each RF net (VCO to SMA, LO,
   both RX paths, balun to mixer) list segments with layer, width and length, the measured gap
   to same-layer ground copper on both sides (from filled zones), the reference plane below and
   whether it is unbroken under the segment, and stitching-via spacing along the pour.
2. `zcalc.py`: microstrip (Hammerstad-Jensen) and grounded coplanar waveguide formulas with
   tests against published reference values and against KiCad's calculator for three cases.
3. Stackups: the board file's stackup, plus JLCPCB's 6-layer impedance stackups (prepreg type,
   thickness, dielectric constant; cite the source page and date) as `stackups.yaml`.
4. Compute impedance and loss per segment for each stackup; identify the JLCPCB stackup and
   trace width/gap that best gives 50 ohm (one design only, built at JLCPCB; the OSH Park
   variant was dropped 2026-11-19); check the LO layer change (F1/F2 return vias), the 0.4 mm
   balun-to-mixer traces, the pad necks and the SMA launch. For the launch and the via, use the
   user's CST Learning Edition where its model-size limits allow: the agent prepares the geometry
   and a checklist, the user runs it, and the exported S-parameters are committed. openEMS in
   `fmcw3-sim` is the open, repeatable fallback and cross-check (decision 2026-11-20).
5. Report and deck: annotated board images per RF net (`kicad-cli pcb export svg`), the
   impedance table, a recommendation of stackup and any width changes, and the text to give the
   fab for controlled impedance. The numbers come from the board file read headless. When the
   project is open in KiCad, `tools/kicad_ipc.py show` selects each flagged segment's net so the
   user can follow along (fnd-06).

## Acceptance
- Every RF net named in step 1 appears with all its segments; none is summarised as "typical".
- Each stackup cites its source; the board-file stackup is labelled as KiCad defaults if so.
- Segments outside 50 ohm plus or minus 10 percent are listed with length in fractions of a wavelength.
- The formulas' test cases and their reference values are named in the report.
- The deck has no more than 20 slides.

## Review
- Open `reports/03_impedance.pptx`: the stackup recommendation and the list of out-of-tolerance
  segments. Compare two flagged segments against the board in the KiCad GUI.

## Out of scope
- Changing trace widths or the board stackup setting.
- Antenna design.
