## Goal
The 1-RX board has its own KiCad project, `kicad-1rx/`, which starts as an exact copy of the 2-RX
design in `kicad/`. Every parts and checks tool works on either project. It holds when ERC and DRC
pass against their baselines for both projects and the copy's netlist equals the original's.
(Added 2026-11-22 at the user's request: two designs, a 1-RX board that JLCPCB can build from
stock by Friday 2026-11-27, and the 2-RX board with the sourced LTC2292.)

## Steps
1. Copy `kicad/` to `kicad-1rx/`:
   - root files renamed `fmcw3_1rx.kicad_pro`, `.kicad_sch` and `.kicad_pcb`, with the
     sub-sheets, `fmcw3.pretty`, `libs/`, `fp-lib-table` and `sym-lib-table` kept;
   - no `.kicad_prl`, lock or backup files;
   - title-block revision set to `1RX-A`.

   Export both netlists with `kicad-cli` and compare them: equal apart from the project name.
   Record the comparison in the Log.
2. Add `--project DIR` (default `kicad`) to:
   - `checks/run_checks.sh`;
   - `parts/bom.py`, `parts/check_jlc.py`, `parts/check_digikey.py` and `parts/watch.py`;
   - `tools/kicad_ipc.py status` (reports whether KiCad has that project open).

   Outputs for `kicad-1rx` go to `parts/out/1rx/`, and the checks baseline goes to
   `checks/baseline-1rx.json` (recorded with `--native --record`). Today's outputs and paths for
   `kicad/` stay unchanged.
3. `tests/test_project_option.py`:
   - each tool resolves the project's files and output paths;
   - `kicad` stays the default;
   - an unknown project directory fails with a clear message.
4. Document `--project` and `kicad-1rx/` in:
   - `MANUAL.md`;
   - `parts/README.md`;
   - `checks/README.md`;
   - the CLAUDE.md "Layout" list (one line: `kicad-1rx/` is the 1-RX variant, under the same
     rules as `kicad/`).

## Rules
- Nothing under `kicad/` is written.
- Write `kicad-1rx/` only while `./run --native tools/kicad_ipc.py status --project kicad-1rx`
  prints `closed`.

## Out of scope
- Any design change in `kicad-1rx/` (rx1-03).
