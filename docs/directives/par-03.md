# par-03: Resolve part numbers and report availability
Status: proposed
Goal: parts
Node: any
Deliverable: slides
Accept: user
Verify: ./run tools/build_report.py analysis/01_parts --check && ./run uv run python parts/check_decisions.py
Hardware: none

## Goal
Every BOM line has a proposed exact part number with its evidence, and the open choices are laid
out for the user to decide. It holds when `parts/decisions.csv` covers every placed line and the
`01_parts` report and deck build.

## Steps
1. For each `No-result` line (20 at the last run), find the orderable suffix from the datasheet
   ordering table whose package matches the footprint; record part, chosen code, datasheet page
   and reason in `parts/decisions.csv`. Use LCSC numbers found on upstream's JLCPCB branches
   (survey fnd-01) as a starting point, each re-checked.
2. Prepare, but do not decide, the user's choices, each with options, stock, price and the
   consequence: XC7A35T or XC7A100T (U30); LTC2292 C or I grade (U8); USB-C receptacle for the
   `GCT_USB4105` footprint; replacement for `SRR6040A-330M` (L5-L7) with saturation current
   checked against the LMR51420 peak current; any part JLCPCB cannot assemble.
3. Propose an MPN for each generic passive group (tolerance, voltage, dielectric stated; C0G for
   RF and filter capacitors), preferring JLCPCB Basic parts.
4. Run `./run parts/bom.py --boards N` live and commit the outputs under `parts/out/`.
   `parts/check_decisions.py` exits 0 only when every placed line has a decision row or an
   entry in the user-choices list.
5. `analysis/01_parts/`: report and deck. Slides: status summary chart, the lines JLCPCB can
   assemble versus consign versus hand-solder, each user choice on its own slide, obsolete or
   risky parts, cost for N boards from both sources.

## Acceptance
- Every placed BOM line appears once in the report tables with MPN, DigiKey status and JLCPCB status.
- Each suffix decision cites the datasheet and page.
- Each user choice has a slide with at least two options and a recommendation labelled as such.
- Figures and tables are generated by `analysis/01_parts/figures.py` from `parts/out/`.
- The deck has no more than 20 slides.

## Review
- Open `reports/01_parts.pptx`. Decide each choice slide (FPGA, ADC grade, USB-C, inductor,
  non-assemblable parts) and give the decisions in the note when you accept this directive.

## Out of scope
- Schematic edits (par-04).
- Ordering.
