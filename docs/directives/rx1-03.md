# rx1-03: Apply the 1-RX schematic changes in kicad-1rx/
Status: approved
Goal: parts
Node: any
Deliverable: code
Accept: user
Verify: ./run checks/run_checks.sh --project kicad-1rx && ./run parts/bom.py --project kicad-1rx --offline --check && ./run uv run pytest tests/test_rx1_netlist.py -q
Hardware: none

## Goal
The 1-RX schematic carries every change the user accepted in rx1-02, and nothing else, so the
user can update the PCB and lay it out. It holds when every netlist difference between `kicad/`
and `kicad-1rx/` is a row of `parts/rx1_changes.csv`, every placed part has its part-number
fields, and ERC has no error type above the 1-RX baseline.

## Steps
1. Preconditions. Stop with `blocked` if rx1-02 is not accepted, or par-04 or par-12 is not done
   (par-12 adds the L5-L7 footprint; amended 2026-11-23). Run
   `./run --native tools/kicad_ipc.py status --project kicad-1rx`; if it does not print `closed`,
   stop and ask the user to close KiCad.
2. AD9237:
   - a symbol in `kicad-1rx/libs/`, built from the datasheet pin table (p.8);
   - a footprint for the 32-lead 5x5 mm LFCSP (CP-32-7), checked against the package drawing
     page, exposed pad included. Use KiCad's library footprint if it matches; otherwise make a
     project footprint.
3. Sheet `adc` in `kicad-1rx/`:
   - replace U8 with the AD9237 per the rx1-02 pin map;
   - add the straps, the decoupling and the 1.5 V bias divider on `/ADC_VCMB` (R990, R991);
   - add R992 (10k, C25744) in series in the PDWN line from U30.B1 (`rx1-pdwn` B); C993-C995 are
     10u 0805 (C15850); R91 / R92 are 5.1k / 12k (`rx1-mode` C). (Amended 2026-11-25.)
   - remove C63, C216 and C219 and the `/ADC_VCMA` net (`rx1-vcma` C). (Amended 2026-11-25.)
   - mark or remove the channel-B nets as rx1-02 says.
4. Other sheets:
   - set the receive-chain-2 parts DNP (excluded from the BOM and position files);
   - apply the accepted stock-only substitutions (symbol, footprint or value) and their fields
     (`MPN`, `Manufacturer`, `DigiKey`, `LCSC`).
   - L5-L7: the Coilank APS0650M330A (JLC C47327223) with the `APS0650` footprint par-12 adds to
     the `kicad-1rx/` library, in place of rx1-02's option A (APS1040M330A). The user chose it for
     both boards on 2026-11-23, subject to par-11. Update the L5-L7 rows of
     `parts/rx1_changes.csv` and `docs/board-changes.md` to match. (Amended 2026-11-23.)
   - Y2 and R19, as par-12 applies them to `kicad/` (rows in `parts/par03_changes.csv`): Y2 to the
     Epson X1G0054210307 (JLC C3007519) in the existing 2.5 x 2.0 mm footprint, and R19 from 0 ohm
     to a 10 nF 0402 DC-cut capacitor, keeping its UUID. Add both as rows of
     `parts/rx1_changes.csv` and `docs/board-changes.md` (Board 1-RX). The rx1-02 stock list
     marked Y2 ok although its part is 3.2 x 2.5 mm on a 2.5 x 2.0 mm footprint. (Amended
     2026-11-23.)
   - U21: the TPS7A4901DGNR (JLC C16430) with its divider, CFF and nets exactly as par-12 applies
     them to `kicad/` (rows in `parts/par03_changes.csv`), replacing rx1-02's TPS7A2401 / MIC5205
     options. Use par-12's step 5 fit result; if par-12 fell back, follow the user's re-evaluated
     choice instead. Add the rows to `parts/rx1_changes.csv` and `docs/board-changes.md`.
     (Amended 2026-11-24.)
   - U12: the YAT-3A+ (JLC C5205332) with the `MC1630` footprint, exactly as par-12 applies it to
     `kicad/`; add the row to `parts/rx1_changes.csv` (replacing rx1-atten's U12 options) and
     `docs/board-changes.md`. U3 keeps the PAT1220-C-6DB-T5 (rx1-atten A). (Amended 2026-11-24.)
5. `tests/test_rx1_netlist.py`: export both netlists headless and check:
   - every difference is a row of `parts/rx1_changes.csv`;
   - every row's change is present;
   - no other net or part changed.
6. Run ERC on `kicad-1rx`. Any new error type is explained in the Log, or fixed. Set the rx1
   rows of `docs/board-changes.md` to `applied (<commit>)`.
7. Ask the user to open `kicad-1rx/` and run Update PCB from Schematic. Footprint placement and
   routing are theirs.

## Review
- Open `kicad-1rx/` sheets `adc`, `opamp_amp`, `power` and `rx`. Check:
  - U8's wiring, straps and the VCMA divider;
  - the DNP marks on the receive-chain-2 parts;
  - the substituted parts and their fields.
- Read the netlist-test result and the ERC note in the Log.

## Out of scope
- Anything in `kicad/` (the 2-RX board).
- Layout and routing (the user).
- Changes not in `parts/rx1_changes.csv`.

## Rules
- Never write `kicad/`. Write `kicad-1rx/` only right after `status --project kicad-1rx` prints
  `closed`.

- `./run *`
