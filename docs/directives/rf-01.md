# rf-01: RF level plan (gain, noise figure, compression) for TX, LO and RX
Status: proposed
Goal: rf-review
Node: any
Deliverable: slides
Accept: user
Verify: ./run uv run pytest tests/test_level_plan.py -q && ./run tools/build_report.py analysis/02_rf_chain --check
Hardware: none

## Goal
A level plan that can be re-run for any target set: power at every node of the TX, LO and RX
paths at 5.8 GHz, cascade noise figure, and margin to each part's limits. It holds when the
`02_rf_chain` report builds and every number traces to a datasheet page or S-parameter file.

## Steps
1. Trace the chain from the netlist (not from memory): VCO U10, splitter R9/R11/R12, pads U12 and
   U3, PA U14, coupler Z1, baluns U26-U28, LNAs U11/U16, gain blocks U9/U13, mixer U29, IF amp
   U45, ADC U8. Store it as `analysis/02_rf_chain/chain.yaml` with refdes and nets; a test checks
   every refdes exists in the schematic export.
2. `analysis/02_rf_chain/stages.csv`: per stage gain or loss, NF, output P1dB, max input, each
   at 5.8 GHz with datasheet, page and condition; S-parameter files via par-02 where published.
3. `level_plan.py`: running power per node, Friis cascade NF, compression margin per stage for
   the target set's TX power, antenna gains, isolation and nearest strong target; LO drive at the
   ADL5802 versus its recommended range with the PA on and off; ADF4158 RFIN level, and its PFD: the firmware runs 40 MHz (R counter 1) while a code comment
   says 32 MHz maximum (survey: `docs/surveys/upstream-survey.md`); state the datasheet limit and, if exceeded, the options
   (R counter change, loop-filter impact for sim-03) as an open decision; RX
   sensitivity and maximum range from the radar equation; IF beat frequency versus the LT6232
   passband and ADC Nyquist (firmware: 40 MSPS, decimate 20 to 2 MSPS per channel, 400 kHz HPF). Unit tests against hand-worked cases.
4. Passive checks: 18 pF DC blocks and 0.5 pF shunt at 5.8 GHz from vendor S-parameters or
   models; bias choke self-resonance; splitter and pad values.
5. Report and deck: block diagram with levels, the level table, margins chart, findings ranked
   by risk, open decisions.

## Acceptance
- Every stage row cites a datasheet page or data file, at 5.8 GHz or with the nearest frequency stated.
- The report states the target set used and rebuilds with `--targets NAME`.
- The LO-drive check and the RX compression check each have an explicit pass, marginal or fail.
- Findings are separated from recommendations; no schematic change is made.
- The deck has no more than 20 slides.

## Review
- Open `reports/02_rf_chain.pptx`: check the target set on the assumptions slide, then the
  findings and decisions slides.

## Out of scope
- Schematic or layout changes.
- EM simulation.

## Rules
- Keep one chain file per board (`chain.yaml` for 2-RX, `chain_1rx.yaml` for 1-RX: one receive path ending at the AD9237 full scale and SNR, plus any substituted RF part such as the baluns or SMA); TX and LO are shared unless a substitute touches them. (amended 2026-11-22 for the two-board plan)
