# rx1-04: 1-RX fabrication and JLCPCB order package
Status: approved
Goal: parts
Node: any
Deliverable: code
Accept: user
Verify: ./run checks/run_checks.sh --project kicad-1rx && ./run parts/order_bom.py --project kicad-1rx --check && friday result check rx1-04 --require 'jlc_ingested == 1' --require 'jlc_short == 0' --files
Hardware: none

## Goal
After the user's layout, the 1-RX board can be ordered from JLCPCB as fabricated and assembled
from stock (target: order by Friday 2026-11-27). It holds when:
- DRC has no unexplained error;
- Gerbers, the BOM and the two-sided placement file are at a new path;
- a same-day stock check shows every line covered for `board_quantity`;
- JLCPCB's quote page has taken the files without edits.

## Steps
1. Stop with `blocked` until the user says the 1-RX layout is done and saved.
2. Run DRC on `kicad-1rx`:
   - unrouted nets: 0;
   - any error type above `checks/baseline-1rx.json` is fixed or written up in the Log for the
     user to disposition.
3. Write Gerbers, drill and the IPC netlist to `fab/1rx/<date>/`, never `production/`, using the
   upstream JLC settings (6-layer stackup as in `kicad/fabrication-toolkit-options.json`).
4. Order files:
   - `./run parts/order_bom.py --project kicad-1rx` (par-05's tool) writes
     `parts/out/1rx/order/jlc_bom.csv` and `jlc_cpl.csv`, both board sides;
   - a fresh JLC stock check that day gives `jlc_short`, the count of lines with JLC stock below
     need, which must be 0;
   - any line that is short goes back to the user with its rx1-02 alternative.
5. The user uploads the Gerbers, BOM and CPL to a JLCPCB assembly quote, up to the parts-review
   page, and reports:
   - whether it took the files without edits;
   - the unmatched lines;
   - whether the placement preview looks right for U8, U30, one connector and one bottom-side
     part.

   Fix and repeat, then record `friday result write rx1-04 --metric jlc_ingested=<0|1>
   --metric jlc_short=<n> --file parts/out/1rx/order/jlc_bom.csv --file
   parts/out/1rx/order/jlc_cpl.csv`. The user places the order.

## Review
- Read the DRC note and the stock check in the Log.
- Check the JLCPCB preview for placement and rotation on both sides.

## Out of scope
- Placing or paying for the order (the user).
- Layout edits (the user).

## Rules
- The agent never logs in, uploads, quotes or orders on JLCPCB or DigiKey.
- Never regenerate or modify `production/`.

## Allowed commands
- `./run *`
- `friday result write rx1-04 *`
